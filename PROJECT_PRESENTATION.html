🎯 Project Overview & Exam Requirements Compliance

Connectify is a modern, responsive, high-performance Social Media Web Application created in strict compliance with the practical exam guidelines for Web Programming.

HTML5 (Semantic Markup) CSS3 (Variables, Dark/Light Modes, Flexbox, Grid) JavaScript ES6+ (Real-time DOM, Async API, AI Chat) Backend PHP (REST Endpoints, JSON Fallback) MySQL Database (Relational Schema)
⭐ Mandatory Requirement Fulfilled: "مع تنفيذ اله حاسبه باستخدام الويب ثابته مع اي فكره من الافكار" A fixed, interactive floating & standalone Web Calculator is fully implemented and accessible across all pages with standard and scientific calculation modes.

🌟 Core Deliverables Implemented

📝 1. Posts Feed Engine

Dynamic feed with instant posting, image uploading, feeling/activity status badges, audience privacy settings, hashtag filtering, and post options (Save, Share, Copy Link, Delete).

❤️ 2. Likes & Multi-Reactions System

Multi-emoji emotional reactions (Like 👍, Love ❤️, Haha 😂, Wow 😮, Sad 😢, Angry 😡) with counter and real-time state synchronization.

💬 3. Comments & Community Discussion

Interactive nested commenting system enabling members to post comments with instant rendering, avatar tags, timestamps, and like triggers.

👤 4. Profile Page & Personal Gallery

Dedicated personal profile with editable cover photo, custom avatar changer, personal biography, employment & education attributes, friends grid, and dynamic photo gallery upload.

🤖 5. Conversational AI Chat & Real-Time Messaging

💬 Floating Messenger Dock with Intelligent AI

Connectify features interactive conversational agents for community members. Users can chat in real time with automated AI personalities, complete with animated typing bubbles, message history persistence, and instant responses without requiring page reloads.

🧮 6. Fixed Persistent Web Calculator (Exam Requirement)

🧮 Features of the Built-in Web Calculator:

  • Persistent Floating Access: Always reachable from a fixed launcher on both index.html and profile.html, plus the navbar and sidebar.
  • Standard Keypad: Addition, subtraction, multiplication, division, decimals, clear (C), clear entry (CE), backspace (⌫), and negation (±).
  • Scientific Mode: Sine, cosine, tangent, square root (√x), square (x²), inverse (1/x), and constants (π).
  • Calculation Tape / History: Saves previous equations to localStorage with click-to-reload capabilities.
  • Social Integration: "Share to Feed" and "Send to Chat" buttons to post math results directly to friends or timeline!
  • Keyboard Support: Direct typing on physical computer keyboards.
  • Dedicated Standalone Page: Also available as calculator.html for full-screen demonstration.

🌗 7. White Mode & Dark Mode Theme Switcher

Universal theme toggle supporting both clean White Mode and high-contrast Dark Mode with persistent theme memory stored in localStorage.
